# Game Playground 试玩反馈

这里仅接收 Game Playground 的游戏故障和体验反馈，不包含私有游戏源码。

试玩入口：https://games.agilooplabs.com （域名接入与验收以实际可访问结果为准）
备用入口：https://game-playground-gp1.pages.dev

[提交问题](https://github.com/wikty/game-playground-feedback/issues/new?template=bug_report.yml) · [已有工单](https://github.com/wikty/game-playground-feedback/issues)

维护负责人：wikty。当前为尽力处理的试玩支持，无固定响应时限。

请提供游戏名称、设备/浏览器、复现步骤、预期及实际结果。网站可导出诊断文件，文件不会自动上传；查看后再决定是否附上。

GitHub 工单及用户名会公开。不要发布凭证、私人存档、个人联系方式或含个人信息的截图。若误提交个人信息，请编辑原工单并联系维护者或 GitHub 隐私渠道。

GP1 是完整可玩试玩版；真人体验验收 HOLD，实体设备、独立音画、权利与商业发行签核仍未完成。没有公网匹配、付费或真钱奖励。
